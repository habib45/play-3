Test Category Image Upload

Supported formats: JPG, JPEG, PNG, GIF, BMP, WebP (Max 5MB)

Instructions:

  1. Start your Play application: sbt run
  2. Fill out the form above
  3. Select an image file
  4. Click "Upload Category"
  5. Check the console for any error messages
  6. Check public/uploads/categories/ for uploaded files

Debug Steps:

  • Open browser developer tools (F12)
  • Go to Network tab
  • Submit the form
  • Check the request details and response
